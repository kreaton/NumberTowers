# Number Towers

A small counting game for kids, built with Blazor WebAssembly (.NET 10). It runs entirely in the browser and can be pinned to a phone or tablet home screen as an app.

## How to play

- There are four towers: blue, red, green and yellow. Each one is built from 1 up to 10.
- Pick bricks from the 4×4 grid. A brick fits only if it has the tower's colour and the next number. The next floor of each tower is marked.
- Tap a wrong brick and it shakes, and a message says which number the tower needs.
- When no brick in the grid fits, the grid shuffles. There is always at least one brick that fits.
- Finish all four towers to win. The timer starts on the first tap.

Extras:

- 💡 (hint) lights up the bricks that fit for a couple of seconds.
- 🔄 **Nyt spil** (new game) asks for a second tap during a game, so a stray touch doesn't wipe out the towers.
- All sounds are made with the Web Audio API in `wwwroot/js/sound.js`, so there are no audio files. Each floor plays a higher note.

## Requirements

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## Run locally

```bash
dotnet run --project src/NumberTowers
```

Then open http://localhost:5054 (or https://localhost:7106 with the `https` launch profile). You can also open `NumberTowers.slnx` in Visual Studio and press F5.

## Publish

Publish with:

```bash
dotnet publish src/NumberTowers -c Release -o src/NumberTowers/bin/Publish
```

The static site ends up in `bin/Publish/wwwroot`. Copy that folder to any static web host.

The app is set up to be served from the `/numbertowers/` subpath (see `<base href>` in `wwwroot/index.html`). If you host it somewhere else, change the base href to match.

## Home screen app

`wwwroot/manifest.webmanifest`, the Apple meta tags in `index.html` and the icons in `wwwroot/icons` let the game be added to the home screen on iOS and Android. It then opens full screen. Pinch-zoom is turned off so little fingers don't zoom the board by accident.

The icons are generated by a script. To regenerate them, run this in Windows PowerShell (it uses System.Drawing):

```bash
powershell -File tools/make-icons.ps1
```

## Project layout

| Path | What it is |
| --- | --- |
| `src/NumberTowers/Game/TowerGame.cs` | Game rules: towers, the brick grid, placing bricks and shuffling |
| `src/NumberTowers/Pages/Home.razor` | The game screen: towers, grid, timer, hints, toasts and the win screen |
| `src/NumberTowers/wwwroot/css/app.css` | All styling and animations, including the portrait and landscape layouts |
| `src/NumberTowers/wwwroot/js/sound.js` | Synthesized sound effects |
| `src/NumberTowers/wwwroot/index.html` | Host page, loading screen and home-screen metadata |
| `tools/make-icons.ps1` | Generates the app icons |
